# 🚗 Vehicle Modification Workshop Management System

A full-featured **Tkinter-based desktop application** to manage a vehicle modification workshop. It supports **Admin**, **Mechanic**, and **Customer** roles with modern UI and complete CRUD operations for each module.

---

## 💡 Features

✅ Role-Based Login System (Admin / Mechanic / Customer)  
✅ Single-Window Navigation (No Popups)  
✅ Modern Sidebar Dashboard  
✅ Full CRUD Operations for All Modules  
✅ Consistent UI Theme Across the App  
✅ Easy to Extend with Database Integration  

---

## 👥 Roles & Access

| Role     | Access Modules                                       |
|----------|-------------------------------------------------------|
| **Admin**    | Customers, Vehicles, Orders, Staff, Parts, Invoices, Feedback, Suppliers |
| **Mechanic** | Orders, Feedback                                  |
| **Customer** | View Own Orders, Submit Feedback                  |

---

## 📦 Modules Included

1. **Login Page** – Authenticates user and directs to role-specific dashboard  
2. **Customers** – Add, update, delete customer records  
3. **Vehicles** – Manage vehicle details  
4. **Orders** – Track and assign vehicle modification orders  
5. **Staff** – Manage staff roles, contact, salary  
6. **Parts Inventory** – Track part availability and pricing  
7. **Suppliers** – Maintain supplier contact and delivery details  
8. **Invoices** – Generate and update billing information  
9. **Feedback & Reviews** – Collect customer ratings and comments
